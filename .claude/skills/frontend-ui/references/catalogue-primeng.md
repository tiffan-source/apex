# Catalogue : besoin d'interface → composant PrimeNG

Version : PrimeNG 21. Import : `import { XxxModule } from 'primeng/xxx'` puis l'ajouter au tableau `imports` du composant standalone.

**Statut**

- **Habillé** : le composant a ses propres réglages dans `libs/design-tokens/src/primeng-preset.ts`. Il est prêt à l'emploi.
- **Harmonisé** : il hérite seulement des couleurs, surfaces, arrondis et du focus du design system. À sa première utilisation dans un écran, vérifier son rendu en clair et en sombre. S'il détonne, faire évoluer le preset (skill `design-system-evolution`), jamais de style local.

## Actions et navigation

| Besoin                              | Composant                                                             | Module                                       | Statut    | Notes                                                                                                                                                                                |
| ----------------------------------- | --------------------------------------------------------------------- | -------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Bouton d'action                     | `<p-button>`                                                          | `ButtonModule`                               | Habillé   | `label`, `icon`, `severity` (`secondary`, `danger`…), `variant="text"` / `"outlined"`, `size="small"`, `[loading]`, `fluid`. Bouton icône seule : `ariaLabel` obligatoire.           |
| Lien qui ressemble à un bouton      | `<a pButton routerLink="…">`                                          | `ButtonModule` (directive `ButtonDirective`) | Habillé   | La directive n'a **pas** d'entrée `variant` : utiliser `[text]="true"`, `[outlined]="true"`, `severity`. Garder les icônes à gauche (`iconPos="top"` n'est pas fiable sur un `<a>`). |
| Barre d'outils, barre de navigation | `<p-toolbar>`                                                         | `ToolbarModule`                              | Habillé   | Sert déjà de barre de navigation flottante (`shell.html`).                                                                                                                           |
| Menu déroulant d'actions            | `<p-menu [popup]="true">`                                             | `MenuModule`                                 | Harmonisé | Ouvert par un `p-button` (`menu.toggle($event)`).                                                                                                                                    |
| Menu à sous-niveaux                 | `<p-tieredmenu>`                                                      | `TieredMenuModule`                           | Harmonisé |                                                                                                                                                                                      |
| Fil d'Ariane                        | `<p-breadcrumb>`                                                      | `BreadcrumbModule`                           | Harmonisé | Pour un simple retour, préférer `<a pButton [text]="true" severity="secondary" icon="pi pi-arrow-left">`.                                                                            |
| Onglets                             | `<p-tabs>`, `<p-tablist>`, `<p-tab>`, `<p-tabpanels>`, `<p-tabpanel>` | `TabsModule`                                 | Harmonisé |                                                                                                                                                                                      |
| Étapes d'un parcours                | `<p-stepper>`                                                         | `StepperModule`                              | Harmonisé |                                                                                                                                                                                      |

## Affichage d'information

| Besoin                           | Composant                                             | Module              | Statut    | Notes                                                                                                                                                          |
| -------------------------------- | ----------------------------------------------------- | ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bloc, carte, panneau             | `<p-card>`                                            | `CardModule`        | Habillé   | Slots `#title`, `#subtitle`, `#header`, `#footer`. Fond particulier : `[dt]="{ root: { background: 'var(--ds-color-accent-soft)', shadow: 'none' } }"`.        |
| Carte cliquable                  | `<a class="ds-link-block" [routerLink]>` + `<p-card>` | `CardModule`        | Habillé   | Modèle : `board.html`.                                                                                                                                         |
| Étiquette de statut ou catégorie | `<p-tag>`                                             | `TagModule`         | Habillé   | `severity` : `danger`, `warn`, `info`, `success`, `secondary`, `contrast`, `primary`. `[rounded]="true"`. Dans un `ds-stack`, ajouter `class="ds-self-start"`. |
| Compteur                         | `<p-badge>`                                           | `BadgeModule`       | Habillé   | `[value]`, `severity`.                                                                                                                                         |
| Pastille d'icône, avatar         | `<p-avatar>`                                          | `AvatarModule`      | Habillé   | `icon`, `size="large"`. Couleur : `[dt]="avatarTone.success"` (`accent`, `success`, `warning`, `danger`, `highlight`), importé de `@org/design-tokens`.        |
| Barre de progression             | `<p-progressbar>`                                     | `ProgressBarModule` | Habillé   | `[value]` de 0 à 100, `[showValue]="false"`.                                                                                                                   |
| Puce                             | `<p-chip>`                                            | `ChipModule`        | Harmonisé |                                                                                                                                                                |
| Séparateur                       | `<p-divider>`                                         | `DividerModule`     | Habillé   | `layout="vertical"` dans une ligne.                                                                                                                            |
| Info-bulle                       | directive `pTooltip="…"`                              | `TooltipModule`     | Harmonisé | Complète un bouton icône seule (avec `ariaLabel`).                                                                                                             |
| Contenu repliable                | `<p-accordion>`                                       | `AccordionModule`   | Harmonisé |                                                                                                                                                                |
| Tableau de données               | `<p-table>`                                           | `TableModule`       | Harmonisé |                                                                                                                                                                |
| Liste paginée ou triable         | `<p-dataview>`                                        | `DataViewModule`    | Habillé   | Pour une simple liste, préférer `<ul class="ds-stack">` (modèle : `objective-overview.html`).                                                                  |

## Retours à l'utilisateur

| Besoin                              | Composant                                                         | Module                                       | Statut    | Notes                                                                                                                                                                                               |
| ----------------------------------- | ----------------------------------------------------------------- | -------------------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Message dans la page (erreur, info) | `<p-message>`                                                     | `MessageModule`                              | Habillé   | `severity` : `error`, `warn`, `info`, `success`, `secondary`. `icon="pi pi-…"`.                                                                                                                     |
| Notification éphémère               | `<p-toast>` + `MessageService`                                    | `ToastModule`                                | Harmonisé | `<p-toast />` est déjà dans `app.html` : injecter `MessageService` et appeler `add({ severity, summary, detail })`.                                                                                 |
| Confirmation avant action           | `<p-confirmdialog>` ou `<p-confirmpopup>` + `ConfirmationService` | `ConfirmDialogModule` / `ConfirmPopupModule` | Harmonisé | Pour toute suppression.                                                                                                                                                                             |
| Modale                              | `<p-dialog>`                                                      | `DialogModule`                               | Habillé   | `header="…"`, `[modal]="true"`, `[style]="{ width: 'var(--ds-dialog-width)' }"`, `[breakpoints]="{ '640px': 'var(--ds-dialog-width-mobile)' }"`, boutons dans `#footer`. Modèle : `edit-task.html`. |
| Panneau latéral                     | `<p-drawer>`                                                      | `DrawerModule`                               | Habillé   | `position="right"`, `[style]="{ width: 'min(var(--ds-drawer-width), 100vw)' }"`. Modèle : `edit-objective.html`.                                                                                    |
| Bulle d'information ancrée          | `<p-popover>`                                                     | `PopoverModule`                              | Harmonisé |                                                                                                                                                                                                     |
| Chargement d'un bloc                | `<p-skeleton>`                                                    | `SkeletonModule`                             | Harmonisé | Pour un contenu qui arrive.                                                                                                                                                                         |
| Chargement ponctuel                 | `<p-progressspinner>` ou `<i class="pi pi-spin pi-spinner">`      | `ProgressSpinnerModule`                      | Harmonisé | Sur un bouton, utiliser plutôt `[loading]`.                                                                                                                                                         |
| État vide                           | aucun composant dédié                                             | —                                            | —         | Modèle maison : `p-card` contenant un `ds-stack ds-items-center ds-text-center` avec `p-avatar`, un texte et un bouton (modèles : `board.html`, `focus.html`).                                      |

## Formulaires

| Besoin              | Composant                                              | Module                                     | Statut    | Notes                                                                                                                                               |
| ------------------- | ------------------------------------------------------ | ------------------------------------------ | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Texte court         | `<input pInputText fluid>`                             | `InputTextModule`                          | Harmonisé | Toujours un `<label for>` au-dessus, dans un `div.ds-stack.ds-gap-2`.                                                                               |
| Texte long          | `<textarea pTextarea fluid>`                           | `TextareaModule`                           | Harmonisé |                                                                                                                                                     |
| Liste de choix      | `<p-select fluid>`                                     | `SelectModule`                             | Harmonisé | `[options]` avec `{ label, value }`. Dans une modale ou un tiroir : `appendTo="body"`. Avec un label : `inputId`.                                   |
| Choix multiples     | `<p-multiselect>`                                      | `MultiSelectModule`                        | Harmonisé | `appendTo="body"` dans un overlay.                                                                                                                  |
| Date                | `<p-datepicker fluid [showIcon]="true">`               | `DatePickerModule`                         | Harmonisé | Traduit en français (`app.config.ts`). Jamais `<input type="date">`. `appendTo="body"` dans un overlay. Le contrôle de formulaire porte une `Date`. |
| Case à cocher       | `<p-checkbox [binary]="true">`                         | `CheckboxModule`                           | Harmonisé |                                                                                                                                                     |
| Interrupteur on/off | `<p-toggleswitch>`                                     | `ToggleSwitchModule`                       | Harmonisé |                                                                                                                                                     |
| Choix exclusif      | `<p-radiobutton>` ou `<p-selectbutton>`                | `RadioButtonModule` / `SelectButtonModule` | Harmonisé | Peu d'options visibles : `p-selectbutton`.                                                                                                          |
| Nombre              | `<p-inputnumber>`                                      | `InputNumberModule`                        | Harmonisé |                                                                                                                                                     |
| Mot de passe        | `<input pInputText type="password">` ou `<p-password>` | `PasswordModule`                           | Harmonisé |                                                                                                                                                     |
| Icône dans un champ | `<p-iconfield>` + `<p-inputicon>`                      | `IconFieldModule`, `InputIconModule`       | Harmonisé |                                                                                                                                                     |
| Libellé flottant    | `<p-floatlabel>` / `<p-iftalabel>`                     | `FloatLabelModule` / `IftaLabelModule`     | Harmonisé | Convention actuelle : libellé au-dessus du champ. Ne pas mélanger les deux styles dans un même formulaire.                                          |
